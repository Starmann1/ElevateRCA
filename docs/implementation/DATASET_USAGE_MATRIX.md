# KONE Elevate — Dataset Usage Matrix

## Purpose
This document catalogs all datasets evaluated for the KONE Elevate prototype, their provenance, accessibility, domain relevance, intended usage, limitations, and classification.

## Dataset Classification Legend
- **REAL PUBLIC DATA**: Externally sourced, publicly accessible real-world dataset
- **SYNTHETIC DATA**: Generated by the controlled simulator/scenario engine
- **PROJECT-AUTHORED KNOWLEDGE**: Fault trees, FMEA, causal links created for the prototype
- **ILLUSTRATIVE DATA**: Example/demonstration data for methodology illustration
- **KONE-SPECIFIC / PROPRIETARY DATA**: KONE internal data (not available)
- **UNKNOWN / UNAVAILABLE**: Source cannot be established

## Evidence Provenance Classes
- **CLASS A — Synthetic Ground Truth**: Generated by controlled simulator
- **CLASS B — Public Real-World Dataset**: External real-world data
- **CLASS C — Project-Authored Engineering Knowledge**: Fault trees, FMEA, causal links
- **CLASS D — Public Engineering Documentation**: Research papers, standards
- **CLASS E — KONE-Specific Source**: Public KONE information
- **CLASS F — Unknown / Unavailable**: Unestablished source

## Critical Disclaimer
> [!WARNING] Critical Disclaimers on Data Provenance
> - **No external dataset directly represents a KONE elevator.**
> - **Synthetic simulation is the primary mechanism for controlled RCA ground truth** in this prototype.
> - **Real public datasets are used to validate component-level algorithms only** (e.g., vibration feature extraction), not system-level causality.
> - **Never present analogous-domain data as direct KONE validation.**

## Detailed Dataset Entries

### 1. Huawei Elevator Predictive Maintenance / Elevator Door Dataset
1. **Dataset Name**: Huawei Elevator Predictive Maintenance / Elevator Door Dataset
2. **Source / URL**: Kaggle, GitHub, Zenodo DOI: 10.5281/zenodo.3653909
3. **License / Accessibility**: Publicly accessible
4. **Domain**: Real elevator car door ball-bearing sensor data
5. **Variables / Features**: 4 Hz sampling, humidity, vibration
6. **Fault Coverage**: Door degradation
7. **Relevance to Project**: High; the ONLY real elevator-specific public dataset available.
8. **Intended Use in Prototype**: Door subsystem validation (door degradation detection)
9. **Limitations**: Door only, no motor/drive/brake/safety data, low sampling rate, no multi-alarm cascades, no competing causal hypotheses.
10. **Actually Used in MVP?**: Yes
11. **Preprocessing Required**: Moderate (feature extraction for low sampling rate)
12. **Provides Ground Truth?**: Yes, for door component degradation (NOT system-level RCA)
13. **Used for Validation?**: Yes - used to validate component-level feature algorithms for door subsystems.
14. **Used for Demonstration?**: Yes - demonstrates handling of real-world noisy sensor data.
15. **Used for Methodology/Reference Only?**: No
16. **Data Classification**: REAL PUBLIC DATA
17. **Evidence Provenance Class**: CLASS B — Public Real-World Dataset

### 2. Case Western Reserve University (CWRU) Bearing Dataset
1. **Dataset Name**: Case Western Reserve University (CWRU) Bearing Dataset
2. **Source / URL**: https://engineering.case.edu/bearingdatacenter/welcome
3. **License / Accessibility**: Publicly accessible
4. **Domain**: Seeded bearing faults on 2hp motor test rig
5. **Variables / Features**: 12kHz/48kHz vibration, multiple fault types and sizes
6. **Fault Coverage**: Bearing inner race, outer race, and rolling element faults
7. **Relevance to Project**: Medium; standard benchmark for vibration analysis, highly analogous to elevator hoisting motor bearings.
8. **Intended Use in Prototype**: Vibration feature extraction algorithm validation
9. **Limitations**: Not elevator data, steady-state continuous rotation only (lacks start/stop elevator dynamics).
10. **Actually Used in MVP?**: Yes
11. **Preprocessing Required**: Standard signal processing (envelope analysis, FFT)
12. **Provides Ground Truth?**: Yes, for bearing fault type/severity. Does NOT provide elevator RCA ground truth.
13. **Used for Validation?**: Yes - validates the signal processing pipeline.
14. **Used for Demonstration?**: No
15. **Used for Methodology/Reference Only?**: No
16. **Data Classification**: REAL PUBLIC DATA
17. **Evidence Provenance Class**: CLASS B — Public Real-World Dataset

3. **License / Accessibility**: Project internal (Proprietary prototype asset)

13. **Used for Validation?**: Yes - validates the end-to-end RCA pipeline and Knowledge Graph resolution.
